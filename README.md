# 西湖区应急管理综合平台

## 一、项目总述

西湖区应急管理综合平台是面向统一门户、台汛监测、预案响应、指挥调度、应急资源、物资库存、风险普查、城市安全、应急值班和灾后复盘的综合产品。项目由原单文件投标演示改造为 Next.js 应用，使用 Supabase 提供身份认证、Postgres 数据持久化和行级权限控制，通过 Vercel 对外发布。

当前版本提供：

- 邮箱密码注册、登录和会话保持；
- viewer、member、admin 三类基础角色；
- 团队邀请码注册和管理员成员权限管理；
- 事件、任务、风险工单的新增、查询、更新和删除；
- 关键操作日志和基础审计追溯；
- Supabase 云端持久化，以及未登录状态下的浏览器本地持久化；
- JSON 数据导入、导出和错误反馈；
- Vitest、Playwright 和 GitHub Actions 自动化检查。
- 预案库、可解释规则匹配、人工启动及指令自动生成；
- 指令已读、反馈、完成和通知渠道跟踪；
- 救援队伍、专家、车辆、装备、机构和避难场所管理；
- 仓库、物资、出入库、调拨和库存预警记录；
- 值班岗位、排班、日志、交接班和通讯录管理；
- 台汛监测与城市安全设备预警体验，模拟数据显著标识；
- 浙政钉、IRS、数据仓、短信、语音、视频、物联网和气象接入台账。

线上地址：<https://xihu-emergency-management-platform.vercel.app>

## 二、使用介绍

### 访客体验

直接打开线上地址即可使用访客模式。访客数据保存在当前浏览器中，刷新页面不会丢失，但不会同步到其他电脑或浏览器。

### 团队成员

1. 使用本人邮箱和独立密码注册，填写团队邀请码。
2. 如系统要求验证邮箱，完成验证后回到平台登录，并再次填写邀请码完成权限激活。
3. `viewer` 只能查看数据；`member` 可以维护本人业务数据；`admin` 可以查看全局数据并管理成员角色。
4. 普通成员的数据默认相互隔离，管理员可以进行全局监督。

邀请码只以哈希形式保存在数据库，不写入 GitHub。如邀请码泄露，可在 Supabase 的 `team_invites` 表中将其 `active` 设置为 `false`。

### 本地开发

1. 运行 `pnpm install && pnpm dev`。
2. 如需更换 Supabase 项目，将 `.env.example` 复制为 `.env.local`，填写 Project URL 和 Publishable Key。
3. 新项目按文件名顺序执行 `supabase/migrations` 中的迁移。
4. 执行 `pnpm lint`、`pnpm test` 和 `pnpm build` 完成本地检查。

浏览器端仅使用 Supabase Publishable Key；数据访问权限由数据库 RLS 策略控制，不得把 secret key 或 service role key 写入前端、仓库或公开日志。
