# 西湖区应急管理综合平台 SOP

## 应急事件处置闭环

```mermaid
flowchart TD
    A[事件线索或风险预警] --> B[登记事件信息]
    B --> C[核实地点、时间、影响和证据]
    C --> D{信息是否完整可信}
    D -- 否 --> E[补充核查并记录原因]
    E --> C
    D -- 是 --> F[研判事件类型与响应等级]
    F --> G[形成事件记录]
    G --> H[下达任务并调配资源]
    H --> I[责任人员查阅并接收]
    I --> J[现场处置与进展反馈]
    J --> K{是否达到处置目标}
    K -- 否 --> L[退回、补充指令或重新调度]
    L --> H
    K -- 是 --> M[复核结果并完成任务]
    M --> N[事件结案]
    N --> O[归档数据与操作日志]
```

## 风险普查数据治理闭环

```mermaid
flowchart LR
    A[发现新增、变更或删减] --> B[创建风险工单]
    B --> C[派单核查]
    C --> D[责任人员确认]
    D --> E{核查是否通过}
    E -- 否 --> F[退回核查]
    F --> C
    E -- 是 --> G[回写风险台账]
    G --> H[留存操作日志]
```

## 角色职责

| 角色 | 主要职责 |
| --- | --- |
| viewer | 查看本人获准访问的信息，不得修改业务数据 |
| member | 登记事件、维护任务、处理风险工单并提交反馈 |
| admin | 查看全局数据、监督处置闭环、管理成员角色和审计日志 |

所有关键动作均应记录操作时间、操作账号、业务对象和处理结果。遇到信息不完整、处置失败或核查不通过时，应回到相应核查或调度节点，不得直接跳过复核结案。
